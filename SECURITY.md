# Security Policy

## Supported Versions

Only the latest released version of tinyedit receives security updates and bug fixes.

| Version | Supported          |
| ------- | ------------------ |
| 0.3.x   | :white_check_mark: |
| < 0.3.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability (such as a buffer overflow, out-of-bounds memory access, or crash triggered by untrusted input), please do **not** open a public issue.

Instead, please report it via one of the following methods:

1. **GitHub Private Vulnerability Reporting**: Use the "Report a vulnerability" button under the **Security** tab of this repository.
2. **Direct Email**: Send an email with details, reproduction steps, and any proof-of-concept files to:
   - Roberto Bissanti: `roberto.bissanti@gmail.com`

### What to include in your report:
- A description of the issue and potential impact.
- Steps or sample files needed to reproduce the problem.
- Terminal environment, OS, and compiler flags used during testing.

You will receive an initial response within 48 hours acknowledging receipt of your report.
